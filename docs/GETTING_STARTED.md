# Getting Started · Stellar Bazaar x402

> Nota en español: esta guía técnica está en inglés. Para la descripción general del proyecto en español, consulta [README.es.md](../README.es.md).

A single ordered journey from a clean machine to a live testnet settlement on
**Stellar Bazaar x402** (Next.js 16 app + read-only MCP server v0.5.0 with 7 tools).

---

## A. Prerequisites

- **Node.js 22.18+ (required).** Several scripts import `.ts` files directly and
  rely on Node's built-in type stripping, which is enabled by default from
  Node 22.18:
  - `scripts/test-agent-autonomous-flow.mjs:3` → `../lib/bazaar-agent-client.ts`
  - `scripts/test-workflow-bundle.mjs:2-5` → `../lib/workflow-bundles.ts`, `../lib/workflow-bundle.ts`, `../lib/catalog.ts`, `../lib/pilot-cards.ts`
  - `examples/agent-autonomous-buyer.mjs:12` → `../lib/bazaar-agent-client.ts`

  With an older Node these fail at import time. Check with `node --version`.
- **npm** (ships with Node) and **git**.
- **A Stellar testnet facilitator API key.** Get one from the OpenZeppelin
  hosted testnet facilitator (dashboard at
  `https://channels.openzeppelin.com/x402/testnet`) or run
  `npm run x402:fetch-facilitator-key`, which calls
  `POST https://channels.openzeppelin.com/testnet/gen` and writes
  `STELLAR_X402_FACILITATOR_API_KEY` into `.env.x402.local`
  (`scripts/fetch-testnet-facilitator-key.mjs`).

## B. Step 0 — Environment files (read this twice)

One-time wallet + key setup, in order (refuses to overwrite existing
`.env.x402.local`, `scripts/setup-testnet-wallets.mjs:2`):

```bash
npm run x402:setup-wallets      # 1. generates + funds payer/seller pair, writes .env.x402.local
npm run x402:fetch-facilitator-key  # 2. writes STELLAR_X402_FACILITATOR_API_KEY into .env.x402.local
cp .env.example .env.local
# 3. merge the wallet values from .env.x402.local into .env.local (see below)
```

Copy the template and understand the two-file chain:

```bash
cp .env.example .env.local
```

- **`.env.local`** is auto-loaded by Next.js for `npm run dev`. It holds the
  server-side x402 envs. This is where you put real values.
- **`.env.x402.local`** is generated by `npm run x402:setup-wallets`
  (`scripts/setup-testnet-wallets.mjs`) and is **NOT** auto-loaded by Next.js
  (Next only auto-loads `.env`, `.env.local`, `.env.development`, `.env.production`).
  It is read explicitly only by wallet/agent scripts
  (`scripts/test-x402-client.mjs`, `scripts/diagnose-x402-server.mjs`,
  `examples/agent-autonomous-buyer.mjs`). **Merge its values into `.env.local`.**
- **Port mismatch warning:** `x402:setup-wallets` writes
  `X402_RESOURCE_BASE_URL=http://127.0.0.1:3210`, but the app runs on **3000**.
  Override it in `.env.local` to `http://127.0.0.1:3000` — this is exactly what
  the repo's own `.env.local` does (line 8). Scripts read
  `X402_RESOURCE_BASE_URL` (`scripts/test-x402-protocol.mjs:4`) and
  `requireLocalResourceBaseUrl()` falls back to `3210` otherwise
  (`lib/x402-config.ts:13`).

## C. Install and run

```bash
npm install
npm run typecheck   # optional; strict TS, 0 errors expected
npm run dev
```

Browse to `http://127.0.0.1:3000` (landing, `/publish`, `/resources`).
The dev server must be running for every suite below.

All script names are from `package.json` (`scripts` block, lines 7-24).

## E. Register a card and consume it

1. Open `http://127.0.0.1:3000/publish` and register a ServiceCard (the human
   flow wraps `POST /api/publisher/ingest`; see [HTTP_API_REFERENCE.md](HTTP_API_REFERENCE.md)
   and [CONFORMANCE_RULES.md](CONFORMANCE_RULES.md) for the schema and the
   11 rules).
2. Confirm it appears in `GET /api/discovery/resources` and in an MCP
   `search_services` call (see [MCP_CLIENT_SETUP.md](MCP_CLIENT_SETUP.md)).
3. Pay for the reference service via `/api/x402/swap-risk` (402 challenge
   flow) or simply run `npm run x402:test-client` for a scripted paid call.

## F. Production

The live deployment is `https://stellar-bazaar-x402.vercel.app` — MCP at
`https://stellar-bazaar-x402.vercel.app/api/mcp`. Production runs
fail-closed on provider auth: without `BAZAAR_PROVIDER_SECRET`,
`/api/publisher/ingest` returns `503 SERVICE_NOT_CONFIGURED`
(`app/api/publisher/ingest/route.ts:20-30`). See
[ENVIRONMENT_VARIABLES.md](ENVIRONMENT_VARIABLES.md) and
[TROUBLESHOOTING_FAQ.md](TROUBLESHOOTING_FAQ.md).
